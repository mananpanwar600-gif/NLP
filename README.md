# Natural Language Processing (NLP)

## Overview

This repository contains my learning journey and practical implementations of Natural Language Processing (NLP) concepts using Python. The project covers text preprocessing, tokenization, stemming, lemmatization, part-of-speech tagging, named entity recognition, and various NLP techniques used in real-world applications.

## Objectives

* Understand the fundamentals of NLP.
* Perform text preprocessing and cleaning.
* Implement tokenization and sentence segmentation.
* Apply stemming and lemmatization techniques.
* Perform Part-of-Speech (POS) tagging.
* Explore Named Entity Recognition (NER).
* Build NLP pipelines using popular Python libraries.

## Technologies Used
